OFDM / OTFS DOUBLY-DISPERSIVE RESEARCH PLATFORM
PROJECT DEVELOPMENT LOG
===============================================

Purpose
-------
This file records the major analysis, validation, correction, and release stages
of the OFDM/OTFS project as reconstructed from the development sequence in this
conversation. It is intended as project provenance and a concise version history.

Important provenance note
-------------------------
The supplied README was intentionally not used as the authoritative project
description because it was known to be outdated. The supplied legacy figures
were also treated as previous-version outputs, not as evidence of the current
implementation. The Raviteja paper was explicitly excluded from the analysis.

The final scientific conclusion is based on the corrected matched
OFDM-vs-OTFS methodology and the final validated result set. The final result
release used a V8.2 base AUDIT with targeted repairs through V8.5; it is therefore
best described as a targeted-repair release rather than a byte-for-byte
homogeneous V8.5 full rerun.

VERSION / DEVELOPMENT HISTORY
=============================

V7.0 / ORIGINAL PACKAGE
-----------------------
Starting point:
- Existing OFDM/OTFS research platform supplied as a ZIP.
- Legacy README was known to be outdated.
- Legacy figures were explicitly identified as previous-version results.
- Several plots, especially Figure 8, were considered potentially incorrect.
- Initial goal: inspect code, assumptions, theory, processing chain, and plots
  rather than trusting historical results.

Key initial concerns:
- OFDM/OTFS comparison methodology was not sufficiently controlled.
- Detector choice was potentially confounding waveform performance.
- Delay and Doppler discretization conventions needed verification.
- E_b/N_0 normalization required consistency across waveforms.
- Channel diagnostics and pilot/CRLB checks contained questionable assumptions.

V7.1-SCI-CORRECTED
------------------
Major corrections introduced:
- Matched OFDM/OTFS detector methodology for the headline comparison.
- OFDM-vs-OTFS comparison moved away from comparing different detector classes.
- E_b/N_0 normalization and waveform accounting were corrected.
- Fractional-delay handling was reviewed and corrected.
- Doppler/PSD handling was corrected.
- MIMO covariance normalization was corrected.
- OTFS pilot matching and delay/Doppler agreement were corrected.
- Random-number generation was isolated from global RNG state.
- Smoke tests were expanded to cover modem, channel, BEM, ICI, covariance,
  noise-domain, pilot, OTFS, AWGN, message-passing, and complexity checks.

Timing validation:
- A timing calibration mechanism was added using measured SMOKE and FAST
  execution points.
- Initial implementation had a MATLAB syntax error in timing_probe.m; it was
  subsequently repaired.
- Timing methodology was upgraded to affine two-point frame scaling where
  appropriate.

First AUDIT:
- Studies 1-5 completed successfully.
- OTFS dominated runtime.
- Crosswaveform initially exposed a struct/numeric mismatch.
- Crosswaveform was then repaired and rerun successfully.

V7.2-SCI-CORRECTED
------------------
Crosswaveform correction:
- Fixed the crosswaveform sparsity-diagnostic assignment:
  sparsity_diagnostic returned a struct while the destination expected numeric.
- Corrected Figure-8 implementation details:
  * wide OFDM numerology was used consistently;
  * physical Doppler definition used Delta-f correctly;
  * OFDM and OTFS waveform durations were matched;
  * both used the same information-symbol budget;
  * matched PCG-MMSE receiver was used for the headline comparison.

V7.3-SCI-CORRECTED
------------------
Numerical identity gate work:
Four validation failures were identified and corrected at the methodology level:
- OTFS energy-preservation check had incorrectly included CP energy in a unitary
  useful-sample identity.
- Water-filling validation/implementation had an incorrect post-hoc power
  scaling behavior.
- LS pilot variance was being compared against a scalar classical bound under
  a doubly-dispersive scenario where the model did not satisfy the assumptions.
- Comb-pilot LMMSE/CRLB validation mixed inconsistent statistical models.

The validation suite was revised so each check is performed under the model
for which the claimed identity actually holds.

V7.4-SCI-CORRECTED
------------------
- LS pilot variance validation was changed from a single random realization to
  an ensemble Monte-Carlo check.
- This addressed an invalid finite-sample variance identity test.

V7.5-SCI-CORRECTED
------------------
- QAM unit-power smoke test was corrected.
- Instead of estimating average constellation power from a small random sample,
  the complete constellation was evaluated for deterministic normalization.
- Smoke test then passed.

First fully gate-passing V7.5 AUDIT:
- Scientific validation gate passed.
- Numerical identity gate passed 33/33.
- All 16 studies completed.
- 13 project figures generated.
- This became the baseline for deeper physical/claimability inspection.

DEEP RESULT / FIGURE AUDIT
===========================
The V7.5 results were then inspected scientifically, beyond code-level gates.

Figure 8:
- Corrected matched OFDM/OTFS comparison was confirmed.
- Equal information-symbol count and equal waveform duration were confirmed.
- Same physical channel and matched PCG-MMSE settings were confirmed.
- Zero-error high-SNR points were identified as finite-sample/censoring effects,
  not literal BER=0 physical floors.
- Diversity slopes were treated as descriptive only, not as universal diversity
  order claims.

Figure 10:
- CP-stress methodology was inspected.
- Need for true inter-block interference under insufficient CP was identified.

Figure 11:
- Clustered EVA Doppler realization was distinguished from an ideal
  Clarke/Jakes process.
- Doppler ACF/PSD diagnostic methodology was found to require correction.

MIMO:
- Perfect-CSI and aged-CSI comparison required further audit.

V8.0-SCI-CLAIMABLE
------------------
Claimability-focused redesign:
- Headline Figure-8 comparison preserved matched PCG-MMSE for both waveforms.
- Zero-error BER points were treated using finite-sample upper bounds.
- Wilson confidence intervals and paired statistics were added.
- McNemar diagnostics were incorporated for paired OFDM/OTFS comparisons.
- Claimability summaries were added.
- Impairment experiments were redesigned to isolate CP stress, phase noise, and
  impulsive noise more clearly.
- Channel diagnostics were expanded to separate clustered EVA from Jakes/Clarke.
- Covariance mismatch and MIMO claimability diagnostics were expanded.

PRIMARY CLAIMABLE SCIENTIFIC RESULT
===================================
The strongest result is the matched OFDM-vs-OTFS comparison.

Experimental conditions:
- EVA doubly selective channel.
- Wide numerology.
- Delta-f = 15 kHz.
- OFDM N = 256, CP = 32.
- OTFS DD grid = 32 x 128.
- 4096 information symbols per frame for both waveforms.
- Equal total waveform duration / 4608 transmitted samples.
- Same physical channel realization for the paired comparison.
- Same truncated PCG-MMSE receiver settings.
- Tested normalized Doppler:
  f_D T_u = 0.01, 0.05, 0.10, 0.20.

At BER = 1e-2, interpolated OTFS SNR advantages were approximately:
- 0.01: 5.13 dB
- 0.05: 4.60 dB
- 0.10: 4.75 dB
- 0.20: 4.37 dB

At 12 dB, measured OTFS BER was approximately 4-9x lower than OFDM
across the tested normalized-Doppler cases.

At higher SNR, OTFS showed very large BER reductions at several Doppler points;
zero observed OTFS errors were reported as finite-sample upper-bounded outcomes,
not literal BER=0 claims.

SAFE WORDING FOR OTFS RESULT
----------------------------
"Under the evaluated EVA doubly selective channel, equal waveform duration and
information-symbol budget, and a matched truncated PCG-MMSE receiver, OTFS
substantially outperformed OFDM across the tested normalized-Doppler range
f_D T_u = 0.01-0.20. At BER = 1e-2, OTFS required approximately 4.4-5.1 dB
less E_b/N_0 than OFDM."

BOUNDARIES OF THE CLAIM
-----------------------
Do not claim:
- universal OTFS superiority;
- universal diversity order 2 for OTFS;
- BER=0 as a physical floor;
- universal robustness to CP deficiency;
- universal Jakes behavior for EVA;
- universal MIMO CSI-aging penalties.

SUPPORTING RESULTS
==================

ICI:
- ICI power increased strongly with normalized Doppler.
- Low-Doppler behavior was broadly consistent with quadratic small-Doppler
  scaling; larger Doppler departed from the simple asymptotic approximation.

Channel estimation:
- Estimator ordering was approximately:
  Vector-Kalman <= LMMSE < DFT-LS < LS
  under the evaluated configuration.
- At 20 dB, vector-Kalman NMSE was approximately 5x lower than LS.

MIMO:
- Corrected ordering:
  perfect-CSI MMSE < aged-CSI MMSE < ZF.
- CSI-aging penalty reached approximately 10.1 dB in the tested configuration
  at the high-SNR operating point.

Phase noise:
- Small phase noise produced limited degradation.
- Larger phase noise caused sharp BER degradation.

Impulsive noise:
- Increasing impulse probability produced measurable but configuration-specific
  BER degradation.

Jakes/Clarke diagnostic:
- Corrected empirical ACF tracked theoretical J0 correlation well.
- Final diagnostic RMSE was approximately 0.0232.
- This validates the generated Jakes reference process; it does not turn the
  clustered EVA channel into an ideal Jakes process.

CP / impairment sensitivity:
- Corrected physical-memory metadata indicates 13 samples of required channel
  memory for the 14-row resolved fractional-delay representation.
- CP stress remains a sensitivity experiment, not a universal robustness claim.
